# DobSpace

Project management app for developer teams (workspaces, projects, sprints, tasks), with a personal layer for individual users that sits alongside their team workspaces.

## Language

**Workspace**:
A team of users collaborating on shared Projects, Tasks, and Sprints.
_Avoid_: Team, organization

**Course**:
A class the user is taking in a given term (e.g. "Fall 2026"), with a name and a color for visual identification. Personal to the user — not shared with any Workspace or team member.
_Avoid_: Subject, class, module

**Assignment**:
A dated item belonging to a Course (homework, exam, quiz, mini project) with a due date, type, priority, and done state.
_Avoid_: Task (reserved for Kanban board items), Deadline, To-do, Project (reserved for Workspace Projects — use "Mini Project" for this assignment type)
